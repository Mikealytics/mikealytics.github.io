# Michael Joyce

Static personal portfolio for enterprise AI leadership, public speaking, and practical work.

Published address: https://mikealytics.github.io/

## Preview

From this directory, run `python3 -m http.server 4173 --bind 127.0.0.1`, then visit `http://127.0.0.1:4173/`.

No build, package installation, backend, or API credentials are required. The core page works without JavaScript. JavaScript only loads the official podcast player on request.

## Publishing

Repository: `Mikealytics/mikealytics.github.io`. GitHub Pages source: `main`, `/ (root)`. Keep `.nojekyll` so GitHub serves the static files directly.

Only this directory belongs in the public repository. The parent project's research, review notes, internal artifacts, and original photo library are not website content.

## Updating

Edit the page text in `index.html`, styles in `assets/site.css`, and optional audio behavior in `assets/site.js`. Keep source qualifications beside figures. Community membership and recording views are dated snapshots, not live counters.

Confirm appearance status before changing a planned or tentative entry. A scheduled date passing does not establish that an appearance was delivered. Keep photo captions attached to the documented event and year.

Media remains with its official publishers. The local podcast image is the official PMI guest artwork, linked to its episode. The audio player loads from Buzzsprout when requested. The full webinar requires sign-in at ProjectManagement.com.

After updates, check the page at mobile/tablet/desktop widths, 200% zoom, keyboard focus, image loading, audio fallback, and source links. After publishing, check HTTPS and the live page. Revert the last website commit to roll back a faulty release.

Font license files accompany the locally served fonts in `assets/fonts/`. Conference photographs are used from Michael Joyce's supplied media library; retain their originals outside this repository.
